EXPERIMENTAL FSR4.0.2 VK IMPLEMENTATION! THINGS WILL BREAK! IF YOU FIND A PROBLEM, @de_w23 ON OPTISCALER DISCORD!

Requirements:
Vulkan 1.1 or newer
RDNA2-based GPU or later


Instructions on usage:
1. Extract a pre-existing Optiscaler 10.0 nightly build into your game as normal.
2. Drop in and overwrite existing Optiscaler.dll within the directory.
3. Drop in amd_fidelityfx_upscaler_vk.dll into the /<game folder location>/Optiscaler/ folder.
4. In the launch args, paste FSR4_VK_ENABLE_DEVICE_FEATURES=1 %command%.
5. Install normally using the bash file.
