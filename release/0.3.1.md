# 0.3.1 — experimental release

This release updates both halves of the native Vulkan integration:

- provider source from `fsr4-vulkan-translation` commit `dc3deb3`;
- OptiScaler source commit `1237d475`;
- optional sharpening routed through OptiScaler's RCAS pass; and
- hardened dispatch metadata, diagnostics, and invalid pre-exposure handling.

The ZIP contains `readme.txt`, `OptiScaler.dll`,
`amd_fidelityfx_upscaler_vk.dll`, and the AMD/OptiScaler license texts required
for redistribution. The provider embeds all ten verified model/preset bundles.
