# 0.3 — private experimental preview

This release repackages the v0.2 binary pair into one ZIP and corrects the
readme requirement from “Vulkan 1.1 or older” to “Vulkan 1.1 or newer.” No
binary code changed from v0.2.

The archive contains `readme.txt`, `OptiScaler.dll`,
`amd_fidelityfx_upscaler_vk.dll`, and the AMD/OptiScaler license texts required
for redistribution.

This remains an experimental private preview. Back up replaced files, do not
use it with online or anti-cheat-protected games, and expect compatibility
issues.
